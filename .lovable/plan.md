# Stop false crash emails and bring workout explanations up to date

## What is happening
Three one-off browser failures were recorded today while opening Tools, Workout of the Day and How It Works. The How It Works page currently opens normally, and the exact file named in its alert is available now; the earlier Workout of the Day file is no longer available. A page can fail to download on someone’s already-open device even when that page’s content has not changed. The nightly health report lists recorded browser errors; that does not mean its page-availability check found How It Works down. The current app sends an immediate crash email for these failed downloads even though its new refresh notice also tries to handle them. The refresh notice has not yet been published to the live site. A transient network failure cannot be ruled out for the How It Works incident, so do not label every such failure an old-version problem.

## Changes
1. **Make failed page downloads recoverable without noisy emails.** Handle recognizable failed page-file downloads in the actual page-error screen as well as the existing branded refresh notice, so a broken navigation offers a working full-page refresh. Keep the existing visual design. Do not report a handled, recoverable download as an app crash; continue to record/alert on other real errors. Group repeat reports of the same missing file sensibly without silencing unrelated failures. Do not change the nightly health checks just to hide these events.
2. **Explain Create Your Own Workout as one feature with two options.** Update its existing section on How It Works and the corresponding About descriptions (phone and desktop): Smarty Coach builds from answers, or Build It Yourself lets a member select exercises from the Exercise Library for the workout’s sections. Show three or four practical benefits within existing copy, not a fifth “way to train” or a new feature/card. Visitors can explore either option; saving the result requires membership.
3. **Explain sharing accurately wherever these pages discuss it.** On How It Works, FAQ and About, say members can share their own Smarty Coach or Build It Yourself workouts; their creator can unshare or delete them. Unsharing removes them from Shared Workouts; deletion removes the workout and social interactions for everyone, while completed/logged training remains in each person’s progress. Workouts merely saved from Shared Workouts are not re-shareable or deletable by the saver. Keep the existing Shared Workouts page and Community behavior unchanged.
4. **Align factual page descriptions.** Update related FAQ answers and page metadata/structured descriptions only where their existing wording describes the old Coach-only workflow or sharing incorrectly. Remove misleading “generated only” phrasing and any demonstrably obsolete offline claim on these touched pages; preserve existing layouts, prices, workout rules and data.

## Verification
- Reproduce a failed page-file download in a browser and confirm the branded refresh option appears, the refresh restores the page, and no immediate crash-alert request is made for that handled case. Confirm an unrelated real error still reaches reporting.
- Check How It Works, FAQ and About on phone and desktop, including the two-option copy, sharing lifecycle and links. Verify the live page still loads and the health report distinguishes recorded browser errors from page availability.
- Run targeted tests, type check and build; review the latest build signal. Publishing to the live site requires a separate publish action.

## Technical details
Use the current root error boundary, update prompt and client error-reporting path rather than adding a second monitoring system. Recognize only dynamic-import/chunk-load failures for recovery; preserve reporting for other failures. Keep FAQ structured data generated from the same visible answers and keep How It Works metadata consistent with the revised section. No changes to workout creation, membership enforcement, sharing/deletion logic, the 530 saved workouts, or their programming rules.
